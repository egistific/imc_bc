# Analysis of imaging mass cytometry data for breast cancer lymph node metastases
This project uses a Snakemake pipeline to analyse imaging mass cytometry data (IMC) from braest cancer tissue microarrays. The data is used in the study by [Fischer and Jackson et al, 2023] (https://linkinghub.elsevier.com/retrieve/pii/S2666-3791(23)00083-6). The code for their study can be found at https://github.com/BodenmillerGroup/BC_LN_metastses.

The code in this repository was tested in Ubuntu 24.04.4 LTS.

## Instructions to run Snakemake pipeline

**1. Clone project repository of your choice and navigate to project folder**
```bash
cd <path/to/directory>
git clone https://github.com/egistific/imc_bc.git
cd imc_bc
```

**2. Create and activate conda environment**
```bash
conda env create -f environment.yaml
conda activate imc
```

**3. Obtain Steinbock Docker image**
```bash
docker pull ghcr.io/bodenmillergroup/steinbock:0.16.1
```

**4. Download raw data into `raw` folder**
Download the TMA slides from IMC acqusitions and place them in the `raw folder`. The slides `ztma21.2.zip` - `ztma21.4.zip` and `ztma25.1.zip` - `ztma25.3.zip` are from (https://zenodo.org/records/7494413) while `ZTMA26.1.zip` - `ZTMA26.3.zip` are from (https://zenodo.org/records/7494509).
```
The files in `metadata` folder are already included in the repository. `Patient_metadata.csv` and `Spillover_matrix.csv` (in `analysis.zip`) are obtained from (https://zenodo.org/records/7494413). `stage1_astir_markers.yaml` contains the Astir marker defintions for the initial stage of cell typing: epithelial, stromal, endothelial, T cell, B cell and myeloid.

**5. Set project path in `config.yaml`**
Set `project.root_dir` as the absolute path of the cloned folder because the Steinbock Docker container mounts it as `/data`.

**6. Raise open-file limit**
Increase the open-file limit to avoid an error while running the pipeline as the snakemake rule `import_steinbock` opens more than 2000 files, beyond the default limit of 1024.
```bash
ulimit -n 65536
```

**7. Run Snakemake pipeline**
```bash
snakemake --cores 1
```

## Pipeline overview

**1. `create_panel`**
- Creates panel file `steinbock/panel_org.csv` from raw .mcd and .txt files.

**2. `edit_panel`**
- Modifies panel file, indicating which channels to discard, and which nuclear and membrane channels to use for cell segmentation. The file is saved as `steinbock/panel_edited.csv`.

**3. `preprocess_images`**
- Performs hot pixel filtering using Steinbock toolkit and saves to `img` folder the images which are in TIFF format.
- Saves image metadata as `steinbock/images_info.csv`.

**4. `segment cells`**
- Performs cell segmentation using Deepcell Mesmer method in Steinbock toolkit. The segmentation masks are saved to `masks_deepcell` folder.

**5. `images_with_masks`**
- Copies images in "img" folder that have segmentation masks to `img_with_masks` folder.

**6. `measure_intensities`**
- Computes mean expression level of each cell for each marker using Steinbock toolkit and saves results to `intensities` folder.

**7. `measure_neighbors`**
- Computes cell neighbourhood graph using Steinbock toolkit and saves results to `neighbors` folder.

**8. `import_steinbock`**
- Reads Steinbock outputs into R `SpatialExperiment` object.
- Adds `metal` and shorter `marker` names.
- Adds image metadata information.
- Discards images that do not have matching patient id.
- Names cells `<sample_id>_<ObjectNumber>` (e.g. `ZTMA21.1_002_1`)
- Saves `SpatialExperiment` object as `analysis/steinbock_single_cell_data.rds`.

**9. `compensate_spillover`**
- Performs spillover compensation using `nnls` method and saves compensated intensity values in `analysis/steinbock_single_cell_data_compensated.rds`.

**10. `filter_cells`**
- Keeps images with `TissueType` `primary tumor` and `lymph node mts` for analysis.
- Removes cells with narrow images (i.e. short side < 200 px) and cells with area < 10 px or > 500 px.
- Performs `asinh` transformation and saves it as `exprs` assay
- Removes cells with low DNA1 signal (`exprs` < 1.2).
- Saves `SpatialExperiment` in `analysis/steinbock_single_cell_data_filtered.rds`.
- Writes input for Astir:
    - Expression matrix: 19 Astir markers that are winsorized at 0.999 quantile; saved as `analysis/astir_exprs.csv`.
    - Design matrix: intercept plus a column per TMA (``batch_col) to correct for batch effects; saved as `analysis/astir_design.csv`.

**11. `run_astir`**
- Fits the Astir model using marker definitions in `metadata/stage1_astir_markers.yaml`
- Corrects for batch effects.
- A cell is labelled "Unknown" when its most likely type is below 0.7.
- Saves probabilities and labels in `analysis/astir_celltype.csv`.
